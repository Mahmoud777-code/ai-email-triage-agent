### Google Calendar Integration

The agent automatically detects meeting requests inside incoming emails:
1. **Schedule Context Awareness:** Pulls upcoming events from your primary calendar to ensure you aren't double-booked.
2. **Event Parsing:** Extracts or suggests appropriate event start/end times in standard ISO format.
3. **Automatic Event Creation:** Creates a Google Calendar invite with the sender added as an attendee.
4. **Contextual Draft Response:** Integrates meeting confirmation details seamlessly into your Gmail response draft.
